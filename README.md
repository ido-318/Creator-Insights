# Creator Insights

פרויקט לימודי לניתוח ביצועי תוכן ולחיזוי מספר אינטראקציות,
באמצעות שני צוותי CrewAI וחוזה נתונים שנבדק בקוד.


## חדש — סביבת העבודה המעוצבת (16.10.2026)

- דשבורד בעברית עם RTL, ניווט לחמש תצוגות, מדדים וגרפים אינטראקטיביים.
- סינון לפי סוג פוסט, חודשי פרסום וקידום ממומן/אורגני; הורדת CSV מסונן.
- השוואת מודלים שקופה מול קו הבסיס, כולל אימות צולב וסטיית תקן.
- דוחות לבחירה ולהורדה והיסטוריית ריצות במסך מערכת.
- שלוש ערכות צבעים, בוררי צבע חופשיים ומצב כהה. שמירה דרך **עיצוב וצבעים** מעדכנת את `.streamlit/config.toml` ונשמרת להפעלה הבאה.
- שכבת Supabase לתמונות מצב של הנתונים, מדדי המודלים והדוחות, עם RLS וגישה מהשרת בלבד.
- תיעוד מקושר ו־Obsidian Base של הפרויקט, כולל ההיסטוריה המתועדת ב־Git.

**מצב Supabase:** קוד החיבור והמיגרציה מוכנים; הפרויקט בענן טרם הוקם, ונדרשת בחירת ארגון. החיבור החי והסנכרון טרם נבדקו. כל הדשבורד זמין גם במצב מקומי.

[מדריך העיצוב](docs/design.md) · [התקנת Supabase](docs/supabase.md) · [מרכז התיעוד ל־Obsidian](docs/obsidian/00%20-%20Creator%20Insights.md)

## מה המערכת עושה?

1. צוות אנליסטים מנקה נתונים, יוצר גרפים ודוח תובנות,
   מפרסם חוזה נתונים ושומר טביעות אצבע של קובצי המסירה.
2. ה־Flow בודק את שלמות המסירה, את החוזה ואת הנתונים.
3. רק לאחר שהבדיקות עוברות, צוות מדעני הנתונים מופעל.
4. צוות המידול משווה קו בסיס ושתי גרסאות CatBoost,
   שומר מודל ודוחות ומאמת מחדש את מדדי הבדיקה.
5. ממשק Streamlit מציג תוצרים ומאפשר הפעלת התהליך.

בכל צוות שלושה סוכנים. חישובי הנתונים והמודלים מבוצעים
בקוד Python, והסוכנים משתמשים בכלים ומסבירים את התוצאות.

## טכנולוגיות

Python, CrewAI, Anthropic Claude, Pandas, Scikit-learn,
CatBoost, Matplotlib, Altair, Streamlit, Supabase (אופציונלי), Obsidian ו־Git.

## התקנה

הפרויקט פותח עם Python 3.13.

מתוך תיקיית הפרויקט, ב־macOS או Linux:

```bash
python3.13 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m pip check
```

## נתוני המקור

מקור: UCI Facebook Metrics
https://archive.ics.uci.edu/dataset/368/facebook+metrics

הנתונים כוללים 500 פוסטים היסטוריים מעמוד Facebook של
מותג קוסמטיקה. נתוני המקור אינם כלולים בתיקיית data במאגר.

1. הורידו את המאגר מהקישור וחלצו את קובץ ה־ZIP.
2. צרו תיקייה בשם data בתיקיית הפרויקט.
3. העתיקו אליה את dataset_Facebook.csv.

הנתיב הנדרש:

```text
data/dataset_Facebook.csv
```

בשלב הניקוי מוסרת שורה אחת שבה חסר הערך Paid.
מתקבלות 499 שורות ושבע עמודות.

## הגדרת Claude

העתיקו את קובץ הדוגמה:

```bash
cp .env.example .env
```

פתחו את .env והחליפו את ערך ANTHROPIC_API_KEY במפתח שלכם.
אין להעלות את הקובץ הזה ל־Git.

הפעלת הסוכנים דורשת גישה למודל המוגדר ויתרת API מתאימה.
קריאות למודל מחויבות לפי השימוש.

## הפעלת הממשק

```bash
python -m streamlit run app.py
```

פתחו את כתובת Local URL שמופיעה בטרמינל.

הממשק נפתח בכתובת `http://127.0.0.1:8501` כברירת מחדל.
הוא מציג תוצרים שמורים; פתיחתו אינה מפעילה קריאות API.
במסך **מערכת**, הכפתור להפעלת התהליך המלא מפעיל את שני הצוותים ומעדכן את התוצרים.
השרת מוגבל למחשב המקומי. לפרסום למשתמשים אחרים נדרשת שכבת אימות והרשאות.

אפשר להפעיל את ה־Flow גם ישירות:

```bash
python project_flow.py
```

יש להפעיל הרצה אחת בכל פעם, מכיוון שהתוצרים נשמרים
בתיקיית artifacts משותפת.

## בדיקות

לאחר הכנת הנתונים והחוזה:

```bash
python test_validation.py
python test_contract.py
python test_handoff_integrity.py
python test_flow_failure.py
python -m unittest test_dashboard -v
```

הבדיקות אינן דורשות קריאות לקלוד. בדיקות הדשבורד כוללות ניווט, סינון ומצב ריק, שמירת ערכות צבעים, הגדרות חיבור, שגיאות רשת ואימות תמונות מצב. קריאות הענן מדומות בבדיקות — הן אינן מאמתות מסד Supabase חי.

הן מכסות:
- עמודה חסרה או לא צפויה.
- ערכים חסרים וערך שעה לא תקין.
- חוזה פגום, שינוי יחידות מוצהרות וגרסה לא נתמכת.
- שינוי בקבצי המסירה לאחר פרסומם.
- חסימת צוות המידול כאשר בדיקת המעבר נכשלת.

בדיקת ה־Flow מדמה את הצוותים, אך מפעילה את בדיקת
המעבר האמיתית על עותקים זמניים.

שינוי מאושר בנתונים דורש פרסום מסירה חדשה.

## חיבור ל־Supabase

לאחר הקמת פרויקט ייעודי, הפעילו את קובץ המיגרציה שבתיקיית `supabase/migrations` והוסיפו ל־`.env` את `SUPABASE_URL` ו־`SUPABASE_SECRET_KEY`.

```bash
python sync_supabase.py --check
python sync_supabase.py
```

אפשר לבדוק ולסנכרן גם מתוך **מערכת → Supabase**, ואז לבחור **Supabase** כמקור הנתונים בצד. אין להעביר מפתח שרת לדפדפן או להעלות אותו למאגר. הוראות ההתקנה, ההרשאות והבדיקה מופיעות ב־[docs/supabase.md](docs/supabase.md).

## תיעוד ב־Obsidian

תיקיית `Creator Insights` בכספת מכילה מרכז ידע, מסמכי ארכיטקטורה, נתונים, מודלים, עיצוב, בדיקות, אבני דרך ו־`Creator Insights.base` עם תצוגות טבלה. עותק הקבצים נשמר גם ב־`docs/obsidian` במאגר. לייבוא לכספת אחרת, העתיקו את תוכן התיקייה לתיקייה בשם `Creator Insights` והפעילו את התוסף המובנה **Bases**.

השחזור ההיסטורי מבוסס על ששת הקומיטים הקיימים ועל תוצרי הפרויקט. אין תיעוד מוסמך לפעולות שקדמו לקומיט הראשון. השינוי הנוכחי מתועד בנפרד כשלב הפיתוח של 16.10.2026; אין כאן טענה שנוצר עבורו קומיט חדש.
