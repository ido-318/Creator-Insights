# מטרות ונתונים

המטרה היא לבדוק קשרים בין מאפייני פוסטים לבין מספר האינטראקציות, ולהדגים מסירה מבוקרת בין צוות אנליסטים לצוות מידול. זו מערכת לימודית ולא מנוע המלצות מוכח.

## מקור וניקוי

[UCI Facebook Metrics](https://archive.ics.uci.edu/dataset/368/facebook+metrics): 500 פוסטים היסטוריים מעמוד Facebook של מותג קוסמטיקה. הקובץ המקומי הדרוש הוא `data/dataset_Facebook.csv`; נתוני המקור מוחרגים מ־Git.

`clean_data.py` מסיר שורה אחת שבה `Paid` חסר וממפה לשבע עמודות. לאחר הניקוי: 499 פוסטים; 425 תמונות, 45 סטטוסים, 22 קישורים ו־7 סרטונים.

| עמודה | משמעות / טווח |
|---|---|
| post_type | Photo / Status / Link / Video |
| category | קוד קטגוריה 1–3 |
| post_month | חודש 1–12 |
| post_weekday | קוד יום 1–7 כפי שהוגדר במקור |
| post_hour | שעה 0–23 |
| paid | 0 אורגני, 1 ממומן |
| total_interactions | מספר אינטראקציות, שלם לא שלילי; משתנה המטרה |

אין להסיק תאריכים מלאים או אזור זמן מהחודש/שעה. אין כותרת או טקסט פוסט בדאטה הנקי. ערכי אינטראקציות גבוהים נשמרים; גבוה אינו בהכרח שגוי. בדיקת כפילויות אינה חלק משלב הניקוי הנוכחי.

החציון הכולל הוא 124, וסך האינטראקציות 105,941. סרטונים מובילים בחציון (271), אך מדובר בשבע תצפיות בלבד. סוג תוכן קשור לביצועים אינו הוכחה לסיבתיות.
