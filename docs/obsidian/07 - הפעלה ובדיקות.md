# הפעלה ובדיקות

## התקנה

```bash
python3.13 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m pip check
cp .env.example .env
python -m streamlit run app.py
```

השלימו מפתח Claude רק בקובץ `.env` המקומי. נתוני המקור צריכים להימצא ב־`data/dataset_Facebook.csv`. הדשבורד מציג תוצרים קיימים גם בלי קריאות Claude או Supabase. [פתיחה מקומית](http://127.0.0.1:8501).

## הרצת התהליך

`python project_flow.py`, או **מערכת → הפעלת התהליך המלא**. זו פעולה שיכולה לחייב שימוש ב־API. יש להריץ פעולה אחת בכל פעם משום שתיקיית התוצרים משותפת.

הרצה דטרמיניסטית ללא סוכנים: `clean_data.py`, `contract_tools.py`, `analysis_tools.py`, `training_tools.py`, `evaluation_tools.py` בסדר זה. היא אינה מייצרת מחדש את כל דוחות הטקסט של הסוכנים.
