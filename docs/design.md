# UI / UX — Creator Insights

## עקרונות

עברית עם יישור לימין; היררכיה ברורה בין מדדים, חקר הנתונים והפעלת המערכת; תוצאות אמיתיות מהתוצרים השמורים; פעולות מחייבות כגון הרצת הסוכנים וסנכרון לענן מתבצעות רק בלחיצה מפורשת.

צבעי ברירת המחדל הם טורקיז `#087F8C`, כחול `#4263EB`, טקסט כחול עמוק `#172B4D` ורקע `#FBFCFE`. הכרטיסים מעוגלים, הגרפים כוללים תיאורים נגישים ותיבות מידע, ומספרים וקוד מוצגים בכיוון קריאה מתאים.

## מפת המסכים

| מסך | תפקיד |
|---|---|
| סקירה | ארבעה מדדים, השוואת סוגי תוכן, מגמה חודשית ותובנה מחושבת |
| חקר נתונים | השוואת תוכן ושעות, טבלה מסוננת והורדת CSV |
| מעבדת מודלים | MAE מול קו בסיס, גודל קבוצות, השוואת CV וסטיית תקן |
| דוחות | בחירה בין ארבעה דוחות והורדת Markdown |
| מערכת | הפעלת Flow, יומן הרצה, בדיקת Supabase, סנכרון והיסטוריה |

סינון לפי סוג תוכן, טווח חודשים וממומן/אורגני משפיע על סקירה וחקר נתונים. תוצאות המודל נשארות תוצאות הניסוי המלא — סינון בדשבורד אינו מאמן מודל חדש. החודש והשעה הם הערכים המקודדים במאגר; אין כאן תאריכי פרסום מלאים או מידע בזמן אמת.

## התאמת צבעים

פתחו **עיצוב וצבעים** בצד: בחרו אוקיינוס, איריס או שקיעה; כוונו צבע ראשי ומשני; בחרו מצב כהה; לחצו **שמירת העיצוב**. הגרפים מקבלים תצוגה מקדימה מיד. שמירה מעדכנת את `.streamlit/config.toml` ושומרת את ההעדפה גם לפתיחה הבאה. ניתן להוריד את קובץ העיצוב.

ההגדרה משותפת לסביבת העבודה המקומית, אינה העדפה פרטית למשתמש. שינוי העיצוב אינו משנה את הנתונים. אם Streamlit לא החיל את הקובץ מיד, רעננו את הדף. צבע ראשי שאינו מספק ניגודיות של 4.5:1 מול טקסט לבן נחסם בשמירה.

הצבעים, הגופנים, הגבולות והמרווחים מבוססים על theme ורכיבים מקוריים של Streamlit. קטע CSS קטן משמש רק לכיוון RTL. גרפים וטבלאות נשארים LTR. הפריסה משתמשת בכרטיסים שנעטפים לשורות במסכים צרים.

## מצבי מערכת

- נתונים חסרים או לא תקינים: הודעה עם הפניה למסך מערכת, ללא קריסת הדשבורד.
- סינון ריק: הסבר ואיפוס מסננים.
- אין תוצאות מודל: הודעה ייעודית; שאר הנתונים עדיין זמינים.
- ריצה אחרונה שנכשלה: אזהרה שהתוצרים עשויים להיות מריצות שונות.
- Supabase לא מוגדר: עבודה מקומית זמינה; בחירה בענן מסבירה מה חסר.
- שגיאת ענן: אינה מציגה מפתחות או גוף תשובת שרת.
